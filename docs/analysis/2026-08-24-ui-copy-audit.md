# UI 문구 전수 감사 — 어색한 표현·중복 라벨·문체 분열 (2026-08-24)

> 발단: 공고카드 조건 칩이 `복장 검정셔츠` / `경력 1년이상` 처럼 **값이 이미 말하는 것을 라벨이 한 번 더 말하는** 구조였고,

## 결론

**맞춤법 오류는 거의 없다. 문제는 전부 "같은 말을 서로 다르게 하는 것"이다.**

## 🔴 P1-2. 같은 상황을 39가지로 말한다

"목록을 못 불러왔다"는 **한 가지 상황**인데 문구가 39개 변이로 존재한다. 4개 축이 제각각 흔들린다.

```
축1 동사   불러오지 못했다 / 불러올 수 없다 / 불러오는데 실패했다
축2 종결   ~어요        / ~습니다
축3 마침표  있음         / 없음
축4 후속안내 "잠시 후 다시 시도" 있음 / 없음
```

실측 예시(모두 동일 상황):

```
공고를 불러오지 못했어요
공고 목록을 불러올 수 없습니다
공고 정보를 불러오지 못했어요. 잠시 후 다시 시도해주세요.
개인정보를 불러오는데 실패했습니다          ← 맞춤법 오류: '불러오는 데'
스케줄을 불러오지 못했어요
스케줄을 불러올 수 없습니다. 네트워크 연결을 확인해주세요
정산 내역을 불러오지 못했어요
정산 목록을 불러올 수 없습니다              ← 같은 정산 도메인 안에서도 갈림
```

같은 문제가 `"찾을 수 없"` 계열 **25변이**에도 있다(`공고를 찾을 수 없습니다` / `공고를 찾을 수 없습니다.` / `공고를 찾을 수 없어요` 3종이 동시에 존재).

## 🟠 P2-2. 개발자 용어가 사용자 화면에 나온다

`위험한 문자열이 포함되어 있습니다` — **44곳**(테스트 제외, JSDoc 예시 1건 별도). zod XSS refine 메시지라, 사용자가 자기소개에 `<` 나 `&` 를 하나 넣으면
"위험한 문자열"이라는 경고를 본다. 정상적으로 글을 쓴 사람에게 **본인이 공격자로 의심받는 인상**을 준다.

기타 노출 문구(고유 31개):

```
올바른 팀 ID 가 아닙니다          ← 'ID 가' 띄어쓰기 오류까지 겹침(19곳)
지원서 ID가 필요합니다
역할 ID는 비어 있을 수 없습니다
날짜는 YYYY-MM-DD 형식이어야 합니다
날짜 형식이 올바르지 않습니다 (YYYY-MM-DD)
admin 직접 수정은 허용되지 않습니다. admin 전용 RPC 를 사용하세요: ${operation}
새로운 구인자 등록 신청이 접수되었습니다. (신청자 ID: ${d.userId || ''})   ← 알림에 UUID 노출
${field} 값이 필요합니다.
입력값을 확인해주세요
```

### 권고

| 현재 | 제안 |
|---|---|
| `위험한 문자열이 포함되어 있습니다` | `사용할 수 없는 문자가 있어요` |
| `올바른 팀 ID 가 아닙니다` | 사용자에게 보일 일이 없어야 함 → `AppError` E7 로 내리고 화면엔 일반 문구 |
| `날짜는 YYYY-MM-DD 형식이어야 합니다` | `날짜를 다시 선택해주세요` (입력이 피커면 애초에 도달 불가) |
| `(신청자 ID: ${userId})` | 알림 본문에서 제거 — 링크로 대체 |

`ID 가` → `ID가` 띄어쓰기 오류는 **19곳**(고유 문구 7개)이다 — `jobPosting.schema.ts`(2) · `jobPostingCollaborator.schema.ts`(4) · `opsParticipant.schema.ts`(4) · `workspace.schema.ts`(7) · `opsParticipantService.ts`(2). 단순 치환으로 즉시 고칠 수 있다.
