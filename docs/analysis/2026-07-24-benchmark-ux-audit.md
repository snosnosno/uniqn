# 벤치마크 UX 감사 — 토스/배민/당근 렌즈 (2026-07-24)

> 목표: "카카오톡·엑셀보다 편하게" — 스태프·사장님 코어 여정 12태스크를 10개 벤치마크 기준(B1~B10)으로 계측.
> 방법: sonnet 계측 에이전트 10개(태스크별 file:line 실측) + 라이브 웹 워크스루(복구 후 10샷) + 메인 세션 교차 검증(HIGH·CRITICAL 4건 소스 직독 확정).
> 설계 스펙: `docs/superpowers/specs/2026-07-24-benchmark-ux-audit-design.md`

## 0. 감사 중 발견·복구한 프로덕션 장애 (별건, 완료)

- **증상**: uniqn.app 웹이 `환경변수 검증 실패(2개 누락)` 동기 무한루프로 부팅 불가(스플래시 동결). 폰트 전량 OTS 디코드 실패.
- **원인**: env 없이 빌드된 번들 배포(번들 내 Supabase ref 0회) + 워크트리 빌드 산출물의 `assets/**/node_modules/**` 폰트를 wrangler가 업로드 제외 → HTML 폴백.
- **복구**: origin/master 워크트리 재빌드(`--clear`) → 중첩 node_modules→vendors 리네임+번들 참조 39건 치환 → 게이트 통과 → 배포. **검증**: 새 번들 `index-e206283d` 서빙·ref 1회 검출·폰트 `200 font/ttf`·실부팅 프로브 정상(`/login` 렌더, 에러 0).
- **재발 방지 후속 → 백로그 R3**: verify-web-build.js에 env 마커 검사 추가 + deploy-cloudflare.js의 중첩 node_modules 처리.

## 1. 한 줄 결론

**입력 마찰은 이미 벤치마크급(지원 텍스트 0·재공고 6탭·QR 1탭)인데, "내 요청이 지금 어디 있는지"(B4 상태 투명성)와 "실패·만료 시 어디로 가는지"(B7 회복 경로)가 체계적으로 비어 있다.** 12태스크 중 9개에서 같은 두 축이 반복 적발됐다 — 개선 투자는 새 기능이 아니라 이 두 축에 집중해야 한다.

## 3. 메타 패턴 — 반복되는 갭 2축 + 1

1. **B4 상태 투명성 공백**: 거절 지원 증발(T3)·신청 상태 미인지(T7)·오늘 출근 미리보기 없음(T11)·수정자 미표시(T12)·지원 여부 미표시(T2). 배민의 "배달 추적"에 해당하는 **"내 요청 지금 어디" 뷰가 전 여정에서 부재**.
2. **B7 회복 경로 공백**: QR 실패(T4)·리뷰 만료(T6)·본인인증 왕복 폼 증발(T7)·작성 중 OS 킬(T8)·expired 재게시(T9)·확정 Undo(T10)·정산 정정(T12). 행복 경로는 잘 닦였는데 **이탈·실패·만료에서 막다른 길**.
3. (긍정) **B3/B5 입력 마찰은 이미 강함**: 이 축에 추가 투자보다 위 2축이 우선.

기존 2026-07-10 감사 대비 **해소 확인**: 노쇼 되돌리기(가능해짐)·시간수정 이중 경로(WorkTimeEditor 단일화)·자정 근무 SSOT·취소 플로우 통합·리뷰 허브 통합·당일 출근 실시간. **미해소 재확정**: 지원 내역 화면·QR 폴백·임시저장·취소요청 인라인·신청 철회.

## 5. 이 감사가 못 본 것

- 실기기 터치·햅틱·성능(코드+웹 실측만). 기존 BLOCKING QA 게이트 그대로.
- 실사용 데이터(탭 수·이탈률) 없음 — CTA 위계·온보딩 제거 폭은 라이브 데이터 확보 후 재조정 권장.
- admin·ops 내부 UX(범위 제외).
- MED·LOW 전수는 각 태스크 에이전트 원보고 기준 — 본 문서는 HIGH 이상 전수 + MED 대표만 수록.
