### 1.3 LTV (v3 — Plan mix 변경 반영)

```
v3 Plan mix (Basic-heavy 가정):
- Basic 60% × ₩3,900 = ₩2,340
- Pro 30% × ₩9,900 = ₩2,970
- Enterprise 10% × ₩29,900 = ₩2,990
- 평균 ARPU = ₩8,300/월

v2 Plan mix:
- Basic 50% × ₩3,900 = ₩1,950
- Pro 35% × ₩9,900 = ₩3,465
- Enterprise 15% × ₩29,900 = ₩4,485
- 평균 ARPU = ₩9,900/월
```

| 축 | Track A | Track B v3 | v2 대비 |
|---|---|---|---|
| 평균 ARPU | ARPPU 7,000원 | **8,300원** | v2 9,900원 → v3 8,300원 (16% ↓) |
| LTV (현실적) | 7,000 × 8 = 56,000원 | **8,300 × (1/0.10) = 83,000원** | v2 99k → v3 83k |
| LTV (낙관) | 10,000 × 12 = 120,000원 | **8,300 × (1/0.06) = 138,000원** | v2 165k → v3 138k |

**v3 변화**: Pro tier 매력이 v2 대비 약간 낮아져 (인재DB/면접제안 등 매력 dim 4개 제거) Plan mix가 Basic-heavy로 이동. 평균 ARPU 16% 하락.

## 2. 수치 시뮬레이션 (사용자 1,000명, v3)

### 2.1 Track A — Year 1 (변경 없음)

```
구인자 100명 × 결제자 30% × ARPPU 5,000원/월
MRR = 150,000원, ARR = 1.8M, LTV = 40k
```

### 2.2 Track B v3 — Year 1

```
구인자 100명 × 결제자 8% (저가 진입장벽 동일)
Plan mix: Basic 60% / Pro 30% / Enterprise 10% (v2 50/35/15에서 Basic-heavy로 이동)
평균 plan 가격: ₩8,300/월

MRR = 100 × 0.08 × 8,300 = 66,400원/월
ARR = 796,800원
LTV = 8,300 × (1/0.10) = 83,000원
```

### 2.3 비교 결론 (Year 1, 1,000명, v3)

| 지표 | Track A | Track B v3 | v2 → v3 변화 |
|---|---|---|---|
| MRR | 150,000원 | **66,400원** | v2 79k → v3 66k (16% ↓) |
| ARR | 1.8M | 0.80M | 동일 비율 ↓ |
| LTV | 40k | **83k** | v2 99k → v3 83k (16% ↓) |
| 결제자 수 | 30 | 8 | 동일 |
| Free→Paid 전환 | 30% | 8% | 동일 |
| Plan mix | N/A | Basic-heavy | v2 Pro-heavy → v3 Basic-heavy |

**v3 핵심 변화**:
- MRR/LTV 모두 약 16% 하락 (v2 대비)
- 이유: Pro tier 차별화 매력 4개 제거 → 사용자가 Basic 머무는 비율 증가
- 그래도 Track A 대비 LTV 우위 (40k vs 83k, 약 2배)
- **컴플라이언스 안전성 확보가 매출 16% 하락보다 훨씬 큰 가치**

### 2.4 Year 2 (사용자 5,000명)

```
Track A:
구인자 500 × 30% × 7,000원 = 1,050,000원/월

Track B v3:
구인자 500 × 8% × 8,300원 = 332,000원/월
```

**격차**: Track A가 v3 Track B의 약 3.2배 (v2 대비 2.6배 → v3 3.2배로 확대).

### 2.5 Hybrid 시뮬레이션 (Track A 기본 + Track B v3 옵션)

```
사용자 1,000명:
- Track A 베이스: 150,000원/월
- Track B v3 추가: 100 × 5% × 8,300 = 41,500원/월 (heavy user 자발 전환)
- Hybrid MRR = 191,500원/월 (단일 Track A 대비 28% ↑)

Year 2 (5,000명):
- Track A: 1,050,000원
- + Track B v3 추가: 207,500원
- Hybrid Year 2 MRR = 1,257,500원/월 (단일 대비 20% ↑)
```

**Hybrid 의의 (v3)**: v2 대비 약간 약화 (24% → 20% 추가 매출), 그래도 의미 있음.

## 3. 컴플라이언스 영향 분석 (v3 신규)

### 3.1 직업정보제공사업 범위 내 운영의 가치

| 영역 | v2 (알선 포함) | v3 (정보 제공만) | 영향 |
|---|---|---|---|
| 법적 리스크 | 직업소개사업 등록 미비 시 위반 | 신고만으로 합법 운영 | **결정적 안전 확보** |
| 등록 비용 | 직업소개사업 등록 부담 | 신고만 (저비용) | **수십~수백만원 절감** |
| 시설 요건 | 직업소개사업: 직업상담사 자격 필요 | 없음 | **인력/공간 비용 0** |
| 수수료 규제 | 알선 수수료 상한 (고용노동부 고시) | 광고 수수료만, 자유 | **가격 정책 자유도 확보** |
| 수수료 형태 | 알선 성공 시 부담 (구인 또는 구직자) | 광고/노출 수수료 (구인자만) | **수익 모델 단순화** |

### 3.2 매출 vs 안전 trade-off

```
v2 (알선 포함, 가정상 합법 운영 가능 시):
- MRR (1k명): 79,000원
- 단, 직업소개사업 등록 비용 + 시설 + 직업상담사 인건비 = 월 100만원+
- 순매출: 마이너스 가능

v3 (직업정보제공사업만):
- MRR (1k명): 66,000원
- 신고 비용 + 컴플라이언스 운영 비용 = 월 10만원 미만
- 순매출: 56,000원/월
```

**해석**: v2의 "16% 매출 우위"는 직업소개사업 등록/운영 비용을 고려하면 **실제로는 v3가 순이익 우위**. 단, MAU가 충분히 커져 (예: 10,000+) 직업소개업 운영비용을 흡수할 수 있는 시점에 v2 모델 (Phase 4)로 진입 가능.

### 3.3 향후 직업소개사업 진입 시점

| Phase | 사용자 규모 | 권장 |
|---|---|---|
| Phase 1~3 (M+0~M+12) | 0~5,000 | 직업정보제공사업만 (v3) |
| Phase 4 (M+13~) | 5,000~10,000 | 직업소개사업 등록 검토 시작 |
| Phase 5 (Y+2~) | 10,000+ | 등록 완료 + AI 매칭/인재DB 출시 (별도 spec) |

## 5. 추천 결론 (CEO 모드, v3)

### 5.1 결론

> **Track A로 출시 → M+3 시점에 Track B v3 paywall layer 추가 (early hybrid) → Year 2부터 직업소개업 등록 검토**

### 5.2 v2 → v3 추천 변화 요약

- Hybrid 진입 시점: **M+3 동일** (가격 매력 유지)
- 알선 기능: **현재 단계에선 포기** (직업정보제공사업 안에서 운영)
- 향후 매칭 기능: **Phase 4 (Year 2+)에서 직업소개사업 등록 + 별도 spec**

### 5.3 근거 (v3 변경 반영)

1. **법적 안전 우선**: 직업정보제공사업 신고만으로 합법 운영 가능. 직업소개업 등록 미비 운영은 위반 (직업안정법 §47 벌칙).
2. **사업비 절감**: 직업상담사 자격, 시설 요건 등 직업소개사업 운영 비용을 사용자 5,000명 시점까지 회피.
3. **차등 dimension 8개로도 충분**: 알바몬/알바천국이 노출 등급 + 광고로만 운영 → UNIQN도 같은 패턴 가능.
4. **공고 무제한이 가져오는 가치**: 모든 매장이 가입할 동기 → DAU/MAU 확대 → 광고 가치 상승 → MRR 증가.
5. **Pivot 비용**: Hybrid 추가 1.5주, 가장 저렴.
6. **Track A spec 진행 중**: 5개 마이그레이션 적용 완료 (5cbdb47c8 ~ a3ce2c598), momentum 활용.

### 5.4 단점 인지 + 대응 (v3)

| 단점 | 대응 |
|---|---|
| Pro tier 차별화 매력 약화 (인재DB 제거) | 브랜드 페이지 + 분석 CSV로 보강 |
| 매출 ceiling 16% 하락 (vs v2) | 직업소개업 등록 비용 회피로 순매출 우위 |
| B2B 영업 무기 감소 | 다중 매장 + 우선 검색 + 전담 CS로 보강 |
| 사용자 알선 니즈 미충족 | Phase 4 별도 spec으로 분리 진행 |

### 5.5 실행 plan (시간순)

```
M+0 ~ M+2: Track A only + 직업정보제공사업 신고
  - 다이아 충전 + 공고당 차감 (이미 진행 중)
  - 사업장 위치 결정 + 신고증 수령
  - 사업자번호 진위 확인 API 연동
  - 청소년/금지 직종 필터 적용

M+3: Track B v3 layer 추가 (Hybrid 시작)
  - 5개 마이그레이션 적용
  - 4-tier paywall (Basic 강조 / Pro 긴급+고정 / Enterprise 우선검색+full브랜드)
  - 분석 대시보드 (CSV) Pro 한정

M+4 ~ M+6: 데이터 기반 최적화
  - 가격/Plan 매력 조정
  - 광고 영역 확장 검토 (메인 배너 등)

M+7 ~ Year 1 말: Enterprise B2B 영업
  - 다중 매장 체인 영업
  - 인보이스 발행 인프라

Year 2+: 직업소개사업 등록 검토
  - 사용자 5,000+ 도달 시
  - AI 매칭/인재DB/면접제안 별도 spec 작성
  - 직업상담사 채용 + 시설 확보
```
