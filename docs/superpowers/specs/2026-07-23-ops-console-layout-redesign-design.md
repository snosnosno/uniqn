## 1. 현재 상태 (As-Is, 코드 검증됨)

`app/(ops)/tournaments/[id].tsx` 193줄, 단일 컴포넌트:
- `tab` 로컬 state 7값(`players|status|tables|levels|staff|history|payouts`), 기본 `'players'`.
- 세그먼트 = `mx-4` 가로 flex, 7탭 균등분할 + `text-xs` 축약 라벨(`:79-110`).
- 클럭(`ClockControl`)·통계(`LiveStatsPanel`)·모니터·등록토글·상태전환이 **전부 `status` 탭 안**(`:118-179`)에 세로 나열.
- 각 탭 콘텐츠는 이미 별도 컴포넌트: `PlayersTab`·`TablesTab`·`BlindLevelsTab`·`StaffTab`·`HistoryTab`·`PayoutsTab`(`src/components/ops/`).
- 반응형 분기 **없음**. `useWindowDimensions` 미사용.

**핵심**: 탭 콘텐츠 컴포넌트는 건드리지 않는다. 바꾸는 건 `[id].tsx`의 **셸(shell) 레이아웃**뿐.

## 2. To-Be 구조

### 2.1 화면 골격 (폰, `width < 600`)

```
┌ StackHeader ──────────────── ⋯ ┐   ⋯ = 상금·이력 오버플로 메뉴
├ ClockStrip (상시) ─────────────┤   레벨·남은시간·블라인드·다음브레이크 / 탭→클럭시트
├ SummaryStrip (상시) ───────────┤   PLAYING·ENTRY·AVG 한 줄 / 탭→현황
├ TabBar 5 ─────────────────────┤   현황·테이블·참가·블라인드·스태프
│                                │
│         (활성 탭 콘텐츠)         │
│                                │
│                          FAB   │   탭별 주 액션
└────────────────────────────────┘
```

- 완료(`completed`) 대회: ClockStrip 자리에 `TournamentResultCard`, 등록 토글 숨김(현행 H7 규칙 유지).

### 2.2 화면 골격 (태블릿, `width ≥ 600`)

```
┌───────────────┬──────────────────────────────┐
│  Sidebar 240  │  TabBar 7 (현황·테이블·참가·    │
│  ─────────────│   블라인드·스태프·상금·이력)     │
│  LEVEL·클럭    ├──────────────────────────────┤
│  블라인드·다음  │                              │
│  ───분리선───  │      (활성 탭 콘텐츠)          │
│  통계 세로목록  │                        FAB    │
└───────────────┴──────────────────────────────┘
```

- 사이드바 = ClockStrip + SummaryStrip의 세로 승격. 어느 탭이든 클럭·통계 상주.
- 상금·이력은 태블릿 탭바에서 흐리게(dim) — "대회 전/후에 보는 탭" 위계 표현.

### 2.3 신규/변경 컴포넌트

| 컴포넌트 | 신규? | 역할 |
|---|---|---|
| `OpsClockStrip` | 신규 | 축약 클럭(레벨·시간·블라인드·다음브레이크). 탭 → 클럭 제어 시트. 완료 시 미표시 |
| `OpsClockControlSheet` | 신규(발췌) | 기존 `ClockControl`을 시트로 감싼 것 — ◀◀/⏸▶/▶▶·±1분·블라인드 구조 링크 |
| `OpsSummaryStrip` | 신규 | `ops_live_stats` 구독 한 줄 요약. 탭 → 현황 탭 |
| `OpsStatusTab` | 신규(추출) | 현행 `status` 탭 콘텐츠에서 **클럭 제외** 나머지(LiveStatsPanel·등록토글·상태·모니터). |
| `OpsConsoleShell` | 신규 | 폰/태블릿 분기 + 탭바 + `⋯` 메뉴 + FAB 슬롯. `[id].tsx`가 이걸 렌더 |
| `useOpsConsoleLayout` | 신규 | `useWindowDimensions` → `{ isWide, ... }`. 600dp 분기 단일 소스 |
| 액션시트(참가/좌석 공용) | 통합 | 기존 `PlayersTab`·`TablesTab` 각자의 행 액션을 **공용 참가자 액션시트**로 수렴(L5) |

### 2.4 액션시트 (L5·L6)

참가자 대상 액션시트를 `OpsParticipantActionSheet`로 단일화, 참가 행/테이블 좌석 양쪽에서 연다:
- 상단: 참가자 정보(#엔트리·이름·칩·좌석)
- 액션 그리드: 정보·자리 이동·좌석 비우기·체크인·리바이·애드온
- **하단 격리 구역**: 탈락 처리(red, 별도 배경). 오탭 방지.
- ITM 도달 bust 시 확인 시트에 "상금 화면 보기 →"(상금 탭으로) — 폰에서 상금이 `⋯`에 있어도 필요 순간 직행.

## 3. 불변 계약 (변경 금지)

- **탭 콘텐츠 컴포넌트 내부 로직·props·권한 분기 불변**. `PlayersTab`/`TablesTab`/`BlindLevelsTab`/`StaffTab`/`HistoryTab`/`PayoutsTab`는 부모가 주는 자리에 그대로.
- 데이터 경로 불변: 전부 기존 훅(`useOpsTournament`·`useOpsParticipants`·`useOpsLiveStats`·`useOpsClock`·`useOpsStaff`…) 구독. 신규 RPC·마이그레이션 **없음**.
- 권한: 현행대로 RLS 단일 진실(멤버 아니면 빈 화면). owner 전용 액션(공고 연결 등)도 현행 유지.
- 완료 대회 H7 규칙(결과카드·등록토글 숨김) 유지.

| 항목 | 판정 |

| 테스트 | 기존 `OpsTournament*` 테스트 유지 + 신규: 반응형 분기(600dp)·액션시트 양쪽 진입·클럭 스트립 상시노출·완료대회 결과카드 |

## 5. 슬라이스 (구현 순서)

1. **S1** `useOpsConsoleLayout`(600 분기) + `OpsConsoleShell`(탭바·⋯·FAB 슬롯) — 기존 탭 그대로 주입, 동작 등가 확인
2. **S2** `OpsClockStrip` + `OpsSummaryStrip` 상시 승격, `OpsStatusTab` 추출(클럭 제거)
3. **S3** 탭 재편(5탭+⋯, 기본 현황) + 태블릿 사이드바 배치
4. **S4** `OpsParticipantActionSheet` 통합(참가·좌석 공용, 탈락 격리) + ITM→상금 링크
5. **S5** 완료대회/엣지·반응형 QA·테스트

각 슬라이스 끝 `npm run quality` + 관련 Jest. 실기기 QA는 사용자 게이트.

## 6. 미해결 / 후속

- 태블릿 사이드바에서 클럭 제어(◀◀/⏸/▶▶) 직접 노출 vs 시트 — S3에서 결정(넓으니 직접 노출 유력).
