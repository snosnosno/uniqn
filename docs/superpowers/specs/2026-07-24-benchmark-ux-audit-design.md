## 2. 대상 태스크 12개

**스태프**: T1 가입→프로필 완성 / T2 첫 공고 발견→지원 / T3 지원 추적·취소 / T4 출근(QR)·근무 / T5 근무이력·급여 확인 / T6 리뷰 작성
**사장님**: T7 사장 전환 신청 / T8 첫 공고 등록 / T9 재공고(두 번째 공고 — 카톡 한 줄과의 진검승부) / T10 지원자 확인→확정 / T11 당일 운영(출근 확인) / T12 정산

## 3. 방법 — 3트랙

1. **코드 실측 팬아웃**: 태스크 묶음별 sonnet Explore 에이전트 10개(5개×2배치)가 화면 수·탭 수·필수 입력·상태 노출·빈상태·Undo·용어를 코드에서 계측. 금지: mcp__supabase__* 호출·파일 수정·성능 주장.
2. **라이브 워크스루**: 배포 웹(uniqn-app.pages.dev)에서 playwright 읽기 전용 흐름(랜딩·로그인·탐색·상세·탭 순회) 실제 확인. 쓰기 태스크는 prod 오염 방지 위해 코드 실측만.
3. **교차 검증**: HIGH급 발견은 메인 세션이 직접 재실측(2026-07-10 감사에서 에이전트 보고 4건 거짓 판명 전례). 종합·판정 = 메인 세션.

모델 라우팅(사용자 지시): 계측=sonnet, 대량 나열=haiku, 종합·판정 등 진짜 중요한 판단만 fable(메인 세션), 구현 없음.
