# ops-web 로컬 수동 테스트 체크리스트 (W1~W8)

> 목적: E2E(`ops-web/e2e/*.mjs`)가 **못 보는 것** — 손맛·속도감·실제 기기 크기·키보드 흐름·두 사람 동시 조작 — 을 사람이 직접 확인한다.
> 자동 검증 현황(2026-09-29, 브랜치 `feat/ops-web-w8`): quality 통과(vitest 397) · E2E 6종(w2·w3·w4·w5·w56·w7) 통과.
> 기록: 항목마다 ✅ / ❌(무엇이·어느 화면 크기에서) 로 표시하고, ❌ 는 스크린샷과 함께 다음 세션에 넘긴다.

## 0. 준비 (5분)

1. Docker Desktop 실행 → `cd uniqn-mobile && npx supabase start`
2. `ops-web/.env.development.local` 확인 — 값은 `npx supabase status -o env` 의 API_URL·ANON_KEY (없으면 `.env.example` 복사)
3. `cd ops-web && npm run local` — 시드 적용 → 전광판 토큰·플레이어 링크·PIN 발급 → 빌드 → http://localhost:4173
   - 화면에 **로그인 주소·계정·콘솔/전광판/플레이어 링크·연결 PIN** 이 찍힌다. 빌드를 건너뛰려면 `npm run local -- --no-build`
   - 실행할 때마다 플레이어 PIN 이 새로 발급되고 연결이 풀린다(계정 연결을 반복 테스트할 수 있게)
4. 브라우저 두 개(또는 일반 창 + 시크릿 창)를 준비한다 — 운영자 A·B, 비로그인 시청자
5. 화면 크기는 개발자도구 기기 모드로: **1280(노트북) · 768(태블릿 세로) · 375(폰)**, 전광판은 **1920×1080**(F11 전체화면)

계정(로컬 전용, 비밀번호 모두 `TestPass1!`): 운영자 `ops-owner@uniqn.test` · 선수 `ops-dealer@uniqn.test` · 가입 미완료 `ops-incomplete@uniqn.test`

> ⚠️ 비밀번호 재설정(§1-3)을 하면 **그 계정의 다른 세션이 전부 끊긴다**(GoTrue 동작). 방치 테스트(§9)와 같이 하지 말 것.
