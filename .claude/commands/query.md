`$ARGUMENTS`(질문)에 위키 기반으로 답한다.

**먼저 `wiki/AGENTS.md` §6(Query 워크플로우)을 읽고 그대로 따른다.**

절차 요약:
1. `wiki/index.md` → `grep "^## \[" wiki/log.md | tail -5` → AGENTS.md
2. 관련 페이지 ≤7개로 좁힘(백링크 1단계 확장 허용)
3. 인용 답변 합성(주장마다 `[[링크]]`), 데이터 갭 명시

출력 형식:
- **답**: 3~10문장, 모든 주장 `[[링크]]` 인용
- **관련 노트**: 열 순서대로 ≤7개 (각 한줄 요약 + 왜)
- **다음 액션**: 데이터 갭 / 모순 / 환류 제안

제약: raw 직접 읽기 지양(부족 시 명시 후 ≤2개) · 읽기 전용(위키 안 씀) · 추측 금지 · 인용 ≥3(못 채우면 갭 처리).
