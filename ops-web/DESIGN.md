# Design System — UNIQN Ops "피트월(Pit Wall)"

> 화면을 만들거나 고치기 전에 이 문서를 먼저 읽는다. 글꼴·색·간격·모션은 여기서 정한 값만 쓴다.
> 바꾸려면 사용자 승인을 받고 아래 결정 기록에 남긴다.
> 조사 근거: `docs/planning/2026-09-28-ops-web-design-research.md` · 시안: `~/.gstack/projects/T-HOLDEM/designs/ops-web-d1-20260928/`

## 제품 맥락

- **무엇**: 홀덤 대회 라이브 운영 웹앱 `ops.uniqn.app` — 운영 콘솔 · TV 전광판 · 플레이어 개인 화면.
- **누가**: 홀덤펍 사장, 대회사 운영팀(플로어·데스크·TD). 어두운 홀, 서서 한 손 조작이 잦다.
- **화면 우선순위**: 태블릿 가로(1024+) → 폰 → 노트북. 전광판은 TV.
- **기억될 한 가지**: **극강의 속도감.** 모든 결정은 "몇 번 만에 끝나는가"로 판정한다.
- **브랜드**: UNIQN 과 별도 서브브랜드. 모회사 골드는 **상금 금액에만** 남긴다(골드=돈, 라임=시간).

## 미학

- **방향**: 실용·계기판(F1 피트월 타이밍 모니터). 감상용이 아니라 0.3초 안에 읽는 화면.
- **장식**: 최소. 포커 칩·카드·펠트 일러스트, 그라데이션, 글래스, 블롭 금지.
- **기본 테마**: 다크. 라이트는 낮 사무실용으로 제공. 전광판은 항상 다크.

## 글꼴 (전부 SIL OFL 1.1, npm 으로 셀프호스팅 — CSP `font-src 'self'`)

| 역할             | 글꼴                               | 패키지                                       | 비고                                        |
| ---------------- | ---------------------------------- | -------------------------------------------- | ------------------------------------------- |
| UI·본문(한글)    | **SUIT Variable**                  | `@sun-typeface/suit`                         | ⚠️ npm `suit` 는 무관한 패키지 — 쓰지 말 것 |
| 표 숫자·코드·키  | **Geist Mono Variable**            | `@fontsource-variable/geist-mono`            | 모노라 자릿수 정렬 자동                     |
| 클럭·전광판 숫자 | **Big Shoulders Display Variable** | `@fontsource-variable/big-shoulders-display` | 좁은 폭 → 같은 폭에 더 큰 숫자              |

- 숫자는 항상 `tabular-nums`. 칩 금액의 천 단위 쉼표는 흐리게(`opacity .45`).
- 숫자 열은 우측 정렬, 나머지는 좌측 정렬. 중앙 정렬은 전광판 클럭뿐.
- **크기(px)**: 11(라벨) · 12 · 14(표 본문) · 16(본문) · 20(강조 숫자) · 28(제목) · 클럭 44(콘솔 스트립) / 40(폰) / `clamp(60px, 11.5vw, 190px)`(전광판). 중간 크기를 늘리지 않는다 — 극단적 대비가 위계를 만든다.
- 라벨: 11px · 600 · 자간 +0.04em · muted.

## 간격 · 레이아웃

- **기본 단위 4px.** 표 행 높이 40px, 터치 모드 52px(주 액션 버튼은 항상 52px). 터치 타깃 최소 44px.
- **카드 그리드 금지** — 정보는 행과 열. 면 구분은 1px 괘선과 명도 차이로만.
- **모서리 2px 하나.** 알약형(9999px)은 상태 칩에만. **그림자 없음**(확인창·시트도 괘선).
- **콘솔 레이아웃(≥1024)**: 상단 고정 클럭 스트립 → 명령줄 → [좌측 레일 168px | 본문 | 우측 상세 패널 340px].
  640–1023: 상단 탭 + 본문, 상세는 우측 시트. <640: 하단 탭 5개, 상세는 바텀시트, 주 액션은 하단 고정 52px 버튼 2개.

## 상호작용

- **확인창은 유지한다(사용자 결정 2026-09-28)**: 탈락·삭제·상금 확정 등 되돌리기 어려운 작업. 기본 버튼=`Enter`, 취소=`Esc`, 열리면 확정 버튼에 포커스. 본문에 판단에 필요한 결과(순위·상금·좌석)를 미리 보여줘 확인 자체가 정보가 되게 한다. **반드시 `ConfirmDialog` 를 쓴다** — 키 자동반복 무시 · 열린 뒤 150ms 무장 · 한 번 열림당 1회 확정 가드가 들어 있다(없으면 Enter 를 누르고 있을 때 3회 확정됨을 실측).
- 서버가 되돌리기를 지원하는 작업(예: `ops_undo_bust`)은 실행 후 **5초 되돌리기 토스트**를 함께 띄운다.
- **명령줄**: 가속 수단(필수 아님). `/` 로 포커스. 예) `7-3 x` 탈락 · `+이름` 등록 · `lv+` 레벨. 모든 명령은 터치로도 같은 결과.
- **단축키**: 선택 상태에서 `X` 탈락 · `R` 리바이 · `M` 이동 · `C` 칩 · `N` 등록. 버튼에 키 표시. **반드시 `useHotkey` 로 건다** — 물리 키 코드(한글 입력 모드 대응) · 입력칸/조합 중/Ctrl·Cmd 조합/다른 대화상자 열림이면 무시.
- 좌석은 길게 누르면 액션 목록(탈락·이동·비우기·체크인).

## 모션 — 입력은 즉시, 연출은 뒤에

- 상태 변경은 **0ms 반영(낙관적 업데이트)**, 애니메이션을 기다리게 하지 않는다.
- 바뀐 칸: 라임 틴트 80ms 켰다가 500ms 페이드(`--flash`).
- 패널·시트 전환 ≤120ms, `cubic-bezier(.2,0,0,1)`. 스프링·바운스 금지. 등장 애니메이션 금지.
- 전광판: 마지막 60초만 초 단위 틱, 레벨 전환 순간 200ms 반전 1회.
- `prefers-reduced-motion`: 색 변화만 남기고 전부 끈다.
